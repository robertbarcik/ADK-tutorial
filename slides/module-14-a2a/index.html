A2A protocol

Agents talking to agents across frameworks and organizations

The thing that outlasts ADK-as-a-framework.

The framing

MCP is agent↔tool.
A2A is agent↔agent.

Both now under Linux Foundation governance.

The journey — fast

  • April 2025 — Google launches A2A at Cloud Next
  • June 2025 — Donated to the Linux Foundation
  • August 2025 — IBM's ACP merged in
  • December 2025 — MCP also donated; both under Agentic AI Foundation
  • Early 2026 — A2A v1.0 spec landed; 5 official SDKs (Py/JS/Java/Go/.NET)
  • Now — ~150 founding-member orgs; ADK integration still @a2a_experimental
Four nouns

Agent Card · Task · Message · Artifact

Memorize these. Rest is commentary.

The four nouns

NounWhatAnalogue
Agent CardJSON descriptor at /.well-known/agent-card.json — identity, skills, authOpenAPI spec for an agent
TaskStateful, server-owned unit of work; has ID, status, history, artifactsA GitHub Issue
MessageOne turn — user or agent — with typed partsA chat message
ArtifactDurable output (reports, images, JSON)An Issue's attachment

Skills are the restaurant's menu; capabilities are whether it does delivery.

Live

Expose an ADK agent as A2A; consume it remotely

Notebook cells 8-14

Expose — to_a2a()

from google.adk.a2a.utils.agent_to_a2a import to_a2a
import uvicorn

root_agent = LlmAgent(
    name="temperature_specialist",
    model=...,
    tools=[convert_c_to_f],
)

app = to_a2a(root_agent, host="localhost", port=8123)
uvicorn.run(app, host="localhost", port=8123)

Any ADK agent → Starlette app → A2A-compliant HTTP service.

Consume — RemoteA2aAgent

remote = RemoteA2aAgent(
    name="remote_temp_agent",
    agent_card="http://localhost:8123/.well-known/agent-card.json",
    description="Remote temperature conversion specialist.",
    use_legacy=False,   # ← critical; skips 3 known bugs
)

# Use it anywhere a regular agent fits — Runner, sub_agents, AgentTool
runner = Runner(agent=remote, ...)

From your side, the remote agent looks local. Under the hood: HTTP, A2A JSON-RPC.

The event stream

USER: Convert 20 degrees Celsius to Fahrenheit.

[tool_call] convert_c_to_f                   ← executed on REMOTE server
[tool_resp] {'celsius': 20, 'fahrenheit': 68.0}
[remote_temp_agent] 68

The tool call ran on the remote server's side of the network. Your side sees a regular event — same shape as a local agent's call.

The critical detail

use_legacy=False

The default is True. Legacy executor has three known bugs: user-message duplication, remote outputs mis-classified as thoughts, sub-agent output loss.

Agent Card structure

{
  "name": "temperature_specialist",
  "description": "Converts Celsius to Fahrenheit...",
  "protocolVersion": "0.3.0",
  "preferredTransport": "JSONRPC",
  "capabilities": { "streaming": false, ... },
  "defaultInputModes": ["text/plain"],
  "defaultOutputModes": ["text/plain"],
  "skills": [
    {
      "id": "temperature_specialist-convert_c_to_f",
      "description": "Convert Celsius to Fahrenheit.",
      "examples": [],
      "tags": ["llm"]
    }
  ]
}

ADK auto-generates this from the agent's name, description, and tools. Production agents author it by hand — populate examples, declare capabilities, sign with AgentCardSignature.

Maturity — honest read

What's real

A2A v1.0 spec is stable. Linux Foundation governance. Five official SDKs. Cross-vendor protocol body.

What's thin

Ecosystem. Most of the ~150 orgs are signatories, not shipping production. ADK integration marked @a2a_experimental. Cross-org trust fabric unfinished.

The framing: A2A is architecture worth understanding, not infrastructure you'd bet production on yet.

Gotchas — six sharp edges

  1. Path rename: /.well-known/agent.json (v0.2) → /.well-known/agent-card.json (v0.3). Older blogs have the wrong path.
  2. Legacy executor: pass use_legacy=False for new code.
  3. Version-pin google-adk + a2a-sdk together. ADK 1.28-1.31 = a2a-sdk 0.3.24.
  4. Discovery is underspecified — .well-known is stable; registries are future work.
  5. Agent Engine is non-spec-default: serves card at /v1/card behind auth, not at .well-known.
  6. Cross-org trust is unsolved. Every cross-org A2A response = untrusted input. Lethal trifecta applies fully.

What to carry forward

Four nouns. Two patterns. Six gotchas.

The protocols outlast the frameworks. Invest accordingly.
