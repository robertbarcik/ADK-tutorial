# Course intro — Speaker notes

---

## Slide 1 — Title

Welcome. AI agents are everywhere right now: in job descriptions, product roadmaps, and startup pitch decks. But there's a wide distance between "I called an LLM API once" and "I have an agent running in production that reads a database, calls APIs, and holds memory across weeks." Over the next fourteen modules, you're going to cross it.

---

## Slide 2 — What you'll build

By the end of this course, you'll have built real working agents. Agents that use four different flavors of tools. Multi-agent orchestrations where one agent calls another. Agents with persistent memory that survives a server restart. Voice-first conversational agents. And fully dockerized agents running as HTTP services. All in Python, all hands-on in runnable Jupyter notebooks.

---

## Slide 3 — Three parts

The course is structured in three parts. Part one, ten modules, covers the vendor-neutral foundation: the same agent code runs on Claude, GPT, Gemini, Qwen, or a local Llama. Part two, three modules, goes deep on Gemini-only capabilities that nothing else in the market replicates: search grounding, context caching, and the Live voice API. Plus a short side step on A2A, the new Linux Foundation protocol for agents talking to other agents across frameworks.

---

## Slide 4 — Why this course

Three things that make this course different. It's hands-on from the first minute, with a runnable notebook in every module. It's vendor-neutral by design, so your code stays portable across providers. And it's built for production, covering memory, evaluation, deployment, and guardrails. If you write Python and you're serious about shipping AI agents, let's get started.
