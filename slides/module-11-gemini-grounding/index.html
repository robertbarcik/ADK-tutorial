Unlock 1

Google Search grounding

Built-in tool. Real citations.

Add google_search to tools

from google.adk.tools import google_search

grounded_agent = LlmAgent(
    name="grounded_agent",
    model="gemini-2.5-flash",
    description="Answers with up-to-date search results.",
    instruction="Use google_search for current-information questions.",
    tools=[google_search],   # ← built-in; Gemini handles the call
)

No custom search tool. No external API. Gemini invokes Search internally and returns cited results.

Cost reality

Search is billed separately
  • ~$35 per 1,000 grounded requests
  • Billed per-request, not per-token
  • Budget accordingly for search-heavy agents
Built-in tools don't mix
  • google_search, BuiltInCodeExecutor, VertexAiSearchTool cannot coexist with regular function tools
  • Wrap each as a sub-agent via AgentTool
  • For Search on ADK ≥ 1.16: pass bypass_multi_tools_limit=True
Unlock 2

Long context + caching

1M tokens. 90% discount on cached input.

Gemini 2.5+

1M tokens input window.
(2M on Pro variants.)

Enough for 500-page manuals, entire codebases, months of email history.

The economics problem

A 100-page PDF is ~50K tokens. Asking 20 questions against it:

No caching:  20 × 50K input = 1M input tokens → $0.075/hour
(You re-pay for the PDF on every question.)

Context caching fixes this. You cache the PDF once. Subsequent queries pay a discounted rate on the cached portion.

Two caching flavors

TypeSetupDiscountControl
ImplicitAuto, zero code~75%None. Gemini decides what to cache.
Explicitclient.caches.create(...) with TTL~90%You pick content and TTL

Implicit: Gemini detects repeated token prefixes automatically. Zero setup, ~75% off cached tokens. Explicit: you name a cache, set a TTL, and reuse it across many sessions. ~90% off. Use explicit when the same large document serves many users.

Explicit caching API

cache = client.caches.create(
    model="gemini-2.5-flash",
    config=types.CreateCachedContentConfig(
        contents=[types.Content(role="user", parts=[types.Part(text=big_manual)])],
        system_instruction="Answer questions about the manual.",
        ttl="300s",   # 5 minutes; billed by the second
    ),
)

resp = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="What is the default wake word?",
    config=types.GenerateContentConfig(cached_content=cache.name),
)

Minimum cache size: ~32,768 tokens. Requires a paid tier — free-tier quota is zero.

Worked example

100-page PDF (50K tokens). 20 questions per hour.

ScenarioCost per hour
No caching$0.075
Explicit caching (create + 20 hits + 1 hour storage)$0.013

~6x cost reduction at 20 queries/hour. Scales further with more queries.

Below 3-5 queries per document per hour, implicit caching (free, auto) covers most of the benefit. Above, explicit is clearly worth the extra code.
