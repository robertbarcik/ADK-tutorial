Callbacks as middleware

Six lifecycle hooks. One return-to-override rule.

Guardrails, caches, PII redaction, mocks.

Callbacks are for agents

what middleware is for web handlers.

Express, Django, Plugin hooks — the pattern is the same.

Six hooks wrap every invocation

EventBeforeAfter
Agent runsbefore_agent_callbackafter_agent_callback
Model callbefore_model_callbackafter_model_callback
Tool callbefore_tool_callbackafter_tool_callback

Plus on_model_error_callback and on_tool_error_callback for error recovery.

The rule

Return-to-override

None → proceed. Value → short-circuit.

The entire callback API

def my_callback(context, request_or_response):
    # Observe, log, validate — whatever.
    if <some condition>:
        return <a replacement value>   # ← ADK uses this; real call skipped
    return None                        # ← real call proceeds

None means "carry on." A returned object means "use this instead." That's it. Same pattern across all six hooks.

Demo 1

before_model_callback

The blocklist guardrail.

Five lines of safety gate

BLOCKED_WORDS = ["password", "secret", "credit card"]

def blocklist_guardrail(callback_context, llm_request):
    latest_user = llm_request.contents[-1].parts[0].text.lower()
    for bad in BLOCKED_WORDS:
        if bad in latest_user:
            return LlmResponse(content=types.Content(
                role="model",
                parts=[types.Part(text=f"I can't help with '{bad}'.")]
            ))
    return None

guarded_agent = LlmAgent(
    ...,
    before_model_callback=blocklist_guardrail,
)

Demo 2

after_tool_callback

PII redaction.

Strip fields before the model sees them

SENSITIVE = {"salary", "ssn", "home_address"}

def redact_pii(tool, args, tool_context, tool_response):
    if isinstance(tool_response, dict):
        cleaned = dict(tool_response)
        for key in SENSITIVE & cleaned.keys():
            cleaned[key] = "[REDACTED]"
        return cleaned
    return None

hr_agent = LlmAgent(
    ...,
    tools=[lookup_employee],
    after_tool_callback=redact_pii,
)

Why this matters

The tool function itself returns the full record. Your Python code is still aware of the sensitive fields — useful for audit logs, database writes, or downstream systems that legitimately need them.

But the model's context contains only what it needs to answer the user's question. You contain the PII blast radius at the callback layer.

Demo 3

before_tool_callback

Mocking for tests.

Short-circuit expensive tools in tests

MOCK_RESPONSES = {
    "AAPL": {"ticker": "AAPL", "price": 180.00, "source": "mock"},
    "GOOG": {"ticker": "GOOG", "price": 140.00, "source": "mock"},
}

def mock_in_tests(tool, args, tool_context):
    if tool.name == "fetch_stock_price":
        ticker = args.get("ticker", "").upper()
        if ticker in MOCK_RESPONSES:
            return MOCK_RESPONSES[ticker]
    return None  # Let the real tool run.

stock_agent = LlmAgent(
    ...,
    tools=[fetch_stock_price],
    before_tool_callback=mock_in_tests,
)

The production win

Same agent code, tests without hitting real APIs.

Inject the callback in tests; leave it off in prod. No separate test doubles.

Six hooks reference

HookUse
before_agent_callbackPre-flight state setup; reject inputs on session conditions
after_agent_callbackFinal-output logging; write summary state
before_model_callbackGuardrails, caching, prompt-injection checks
after_model_callbackResponse filtering; telemetry; cost tracking
before_tool_callbackMocking, cache lookups, argument validation
after_tool_callbackPII redaction, result caching, error classification

When to pick callbacks vs alternatives

MechanismScopeWhen
Instruction promptOne agentSoft preferences, style
Tool function codeOne toolGuards on irreversible ops (M02)
CallbackOne agent's lifecycleCross-cutting concerns — guardrails, PII, caching
Plugin (newer)Whole runner, all agentsOrg-wide policies; audit logging

Rule: callbacks for agent-specific logic, plugins for app-wide policy.

The observability gotcha

Callbacks don't appear in traces

ADK's OpenTelemetry traces include LLM calls, tool calls, state deltas. They do not include "before_model_callback ran, returned None" as a span.

If you rely on callbacks for policy decisions in production, add explicit telemetry inside the callback — a print, a log line, or a manual span.

Known gap. Documented in Google's ADK blog.

What to carry forward

Six hooks. One rule: return None or return a value.

Guardrails, redactors, mocks, caches — same pattern, different return.
